# ربات تلگرام دیده‌بان ۲۴ ساعته کافه‌بازار و مایکت (Bazar & Myket 24h Radar)

این مخزن شامل ربات تلگرام پایتون و ورک‌فلوی خودکار **GitHub Actions** است که هر ۲۴ ساعت یک‌بار، تمام دسته‌بندی‌های **کافه‌بازار** و **مایکت** را از طریق API رسمی کلاینت بررسی کرده و جدیدترین برنامه‌های هر دسته‌بندی (شامل **نام برنامه**، **آیکون برنامه** و **توضیحات کامل برنامه**) را به تلگرام ارسال می‌کند.

## ساختار فایل‌ها
```text
├── .github/workflows/daily-radar.yml
├── bot.py
├── requirements.txt
├── seen_apps.json
└── README.md
```

## راه‌اندازی در گیت‌هاب (۳ گام ساده)
1. تمام فایل‌های این پکیج را در مخزن گیت‌هاب خود آپلود (Push) کنید.
2. در مخزن گیت‌هاب به مسیر **Settings → Secrets and variables → Actions → New repository secret** بروید و دو متغیر زیر را بسازید:
   - `TELEGRAM_BOT_TOKEN`: توکن ربات تلگرام دریافتی از `@BotFather`
   - `TELEGRAM_CHAT_ID`: آیدی عددی چت یا نام کاربری کانال (مانند `@my_channel`)
3. وارد تب **Actions** شوید، ورک‌فلوی **Bazar & Myket 24h Telegram Radar** را انتخاب کرده و روی **Run workflow** کلیک کنید.
